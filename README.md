# Página de solicitação de portfólio profissional

## Publicação em repositório separado
1. No GitHub da conta BertaT2C, clique em **New repository**.
2. Nomeie como `Queromeuportfolio` e marque **Public**.
3. Envie `index.html`, `obrigado.html` e `README.md` para a raiz.
4. Em **Settings → Pages**, selecione **Deploy from a branch**, branch `main`, pasta `/ (root)` e salve.
5. O endereço esperado será https://bertat2c.github.io/Queromeuportfolio/

## Recebimento por e-mail
O formulário está endereçado a `bertareg@hotmail.com` e usa o assunto fixo `NOVO PEDIDO | PORTFÓLIO PROFISSIONAL`.
O backend é FormSubmit: após publicar, faça um envio de teste e confirme a ativação/verificação enviada para o e-mail. Depois teste novamente. O formulário permite currículo PDF/DOC/DOCX e limita o envio a 10 MB.

A documentação do FormSubmit informa limite total de 10 MB por envio para upload nativo. O arquivo é encaminhado como anexo de e-mail. Revise os termos e a política de privacidade do fornecedor antes de receber currículos reais.

## Privacidade
- Não coloque currículos nem dados de clientes no GitHub.
- O repositório contém apenas código estático.
- Consentimento para análise dos dados é obrigatório; contato via WhatsApp é opcional.
- Não há cobrança no envio do formulário.
